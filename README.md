# Creative Attempt

Creative Attempt is a modern platform for buying, selling, and collecting digital images and art pieces. Users can upload their own artwork, add a title and price, publish it in the gallery, discover works created by others, purchase them, and build their own collection.

The platform is designed as an intuitive marketplace for digital art, where each card is more than just an image — it becomes part of a personal collection that can be sold, traded, or preserved as a valuable item.

https://creative-attempt.vercel.app/

## Key Features

- Upload your own images
- Add a title and price for sale
- Browse the gallery with search and sorting
- Buy artworks from other users
- Collect cards in your own library
- Unlock achievements for activity and collection growth
- Modern UI for a smooth experience

## Current Project Status

This is an MVP/prototype of the platform with core pages for:

- the homepage;
- artwork creation;
- the gallery;
- user profile;
- About, Contact, and Settings pages.

## Technologies

- Next.js 16

- CSS Modules
- Tailwind CSS

## Quick Start

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the app in your browser:

```text
http://localhost:3000
```

## Useful Commands

```bash
npm run build
npm run lint
```

## Project Goal

Creative Attempt is being created as a platform where creativity has not only visual value, but also economic value. Every user can become an author, buyer, collector, and creator of their own digital collection.
